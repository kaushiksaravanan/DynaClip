# DynaClip 0.3.0

## Highlights

- Reworked the UI into a Windows Dynamic Island-style experience
- Added tray icon support and a global hotkey (`Ctrl+Shift+Space`)
- Added persistent settings and startup support
- Added multi-window clip detail pop-outs
- Added support for text, file-list, and bitmap-image clipboard entries
- Added release assets for packaging and QA

## Operational Improvements

- Single-instance protection
- Local rotating logs
- Version resource metadata
- Smoke-test script
- Release checklist and QA matrix
