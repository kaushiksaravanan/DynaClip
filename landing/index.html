Security posture

Built to keep clipboard utility from becoming clipboard risk.

DynaClip keeps clipboard history in memory, encrypts persisted settings and diagnostics with Windows DPAPI, and can skip obviously sensitive text before it is ever added to history.

Encrypted local settings

Run-at-startup, auto-capture, and security toggles are stored with DPAPI instead of plaintext registry values.

Sensitive text filtering

Patterns such as passwords, API keys, bearer tokens, and overly long text blobs can be blocked from history.

Auto-purge window

History ages out automatically so the app keeps less sensitive material resident in memory over time.

Encrypted diagnostics

Operational logs are stored encrypted and never contain clipboard payload data.

Windows-native

Top-edge reveal, tray integration, and startup hooks

Feels like a desktop utility instead of a floating web app.

Multi-format

Text, file lists, and bitmap image clipboard flows

Quickly restore the clipboard in the same shape it was captured.

Multi-window

Open clips in dedicated detail windows

Inspect longer entries without forcing the island open all the time.

Release readiness

Shaped for a production release cycle.

The repo includes build scripts, installer assets, QA matrices, release notes, and a pre-release audit so shipping the app is a workflow, not a guess.
